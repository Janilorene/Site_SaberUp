Voltar Fluxo Completo: CRUD → Quizzes

Como os jogos são cadastrados e exibidos nos tópicos

🖥️ 1. Front-end cadastra o jogo no CRUD

O usuário preenche o formulário de cadastro no CRUD e envia os dados via fetch:

form.addEventListener("submit", e => {
  e.preventDefault();
  const data = {
    serieJogo: serieSelect.value,
    titulo: document.getElementById("titulo").value,
    materia: materiaSelect.value,
    topico: topicoSelect.value
  };
  fetch("/jogo", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data)
  }).then(() => {
    form.reset();
    listarJogos(); // atualiza lista no CRUD
  });
});

➡️ Aqui começa o fluxo: Front-end → POST /jogo.

⚙️ 2. Aplicacao.java recebe POST /jogo

post("/jogo", (req, res) -> {
    Jogo j = gson.fromJson(req.body(), Jogo.class);
    jogoService.add(j.getSerieJogo(), j.getTitulo(), j.getMateria(), j.getTopico());
    return "Jogo cadastrado!";
});

➡️ Spark converte JSON e chama o Service.

🧠 3. JogoService adiciona o jogo

public void add(int serieJogo, String titulo, String materia, String topico) {
    Jogo j = new Jogo(0, titulo, materia, serieJogo, topico);
    jogoDAO.insert(j);
}

➡️ O Service encapsula a lógica de negócio e delega para o DAO.

💾 4. JogoDAO insere no banco

String sql = "INSERT INTO jogo (titulo, materia, serie_jogo, topico) VALUES (?, ?, ?, ?)";
try (Connection conn = getConnection();
     PreparedStatement stmt = conn.prepareStatement(sql)) {
    stmt.setString(1, j.getTitulo());
    stmt.setString(2, j.getMateria());
    stmt.setInt(3, j.getSerieJogo());
    stmt.setString(4, j.getTopico());
    stmt.executeUpdate();
}

➡️ Agora o jogo está persistido no banco.

📋 5. Front-end atualiza lista de jogos

function listarJogos() {
  fetch("/jogos")
    .then(res => res.json())
    .then(jogos => {
      lista.innerHTML = "";
      jogos.forEach(j => {
        // gera cards HTML para cada jogo
      });
    });
}

➡️ O CRUD mostra o jogo recém-cadastrado

🧭 6. Página de Quizzes carrega jogos do tópico

// Pega o parâmetro "topico" da URL
const params = new URLSearchParams(window.location.search);
const topico = params.get('topico');

// Faz a requisição ao back-end para buscar os jogos daquele tópico
fetch(`/jogos?topico=${encodeURIComponent(topico)}`)
  .then(res => res.json())  // converte a resposta em JSON
  .then(quizzes => {
    // Cria cards HTML para cada jogo retornado
    quizzes.forEach(q => {
      // código que cria os cards com q.titulo, q.materia, etc.
    });
  });

➡️ O fetch envia para o back-end o nome do tópico e recebe de volta a lista de jogos desse tópico.

O JavaScript então cria dinamicamente os cards

⚙️ 7. Aplicacao.java recebe GET /jogos

get("/jogos/topico/:topico", (req, res) -> {
	String topico = req.params(":topico");
	res.type("application/json");
	return gson.toJson(jogoService.listarPorTopico(topico));
});

➡️ Spark encaminha para JogoService → JogoDAO → Banco e devolve JSON.

Conclusão

  1. Usuário cadastra jogo no CRUD.
  2. POST /jogo → Spark → Service → DAO → banco.
  3. CRUD atualiza lista automaticamente.
  4. Próximo GET /jogos (em quizzes.html) retorna também o novo jogo.
  5. Quizzes do tópico exibem o jogo cadastrado.
